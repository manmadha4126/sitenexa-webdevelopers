## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/sitenexa/sitenexa-webdevelopers.git
   cd sitenexa-webdevelopers
   ```

2. **Install dependencies**
   ```bash
   bun install
   ```

3. **Start development server**
   ```bash
   bun run dev
   ```

4. **Build for production**
   ```bash
   bun run build
   ```
